# Native SwiftUI prototype (not built)

Early fully-native SwiftUI prototype of UNTO / FLOW (models, Metal tomato shader, card views,
timer coordinator, tests). It is **not** part of the Xcode app target.

The iPhone app that is actually built (`FableFlow.xcodeproj`) is a thin native shell around the live
web app (`FableFlow/App/UntoFlowWebContainerView.swift`) plus a Home Screen widget (`UntoFlowWidget/`).
These files are kept for reference only.
